Backup e funcionamento

Esta é a carteira original integrada ao Auditor Fiscal. Clientes, tarefas, checklists, anotações, repetições e conclusões são salvos no SQLite do sistema, não no navegador.

Use Importar clientes do HTML para trazer os cadastros iniciais. Para trazer alterações feitas na agenda antiga, baixe o backup JSON nela e restaure aqui.

Restaurar substitui a carteira atual e baixa um backup antes. Excluir um cliente remove suas atividades da carteira; os documentos e o cadastro fiscal são preservados. Conclusões mensais da carteira não representam fechamento fiscal ou envio de obrigações.

Prazos e honorários são informados manualmente. Não há notificações com o sistema fechado. Repetições não ajustam feriados.

Para usar no Windows, mantenha Iniciar-Windows.bat aberto. Atualizações devem preservar a pasta data. Não é necessário criar um novo atalho do HTML antigo.
